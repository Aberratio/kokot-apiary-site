# kokot-apiary-site

Client website for Franciszek Kokot, a beekeeper. One-page site, custom CMS for the offer, no online payments.

## Language rule (mandatory)

Everything in this repository is written in **English**: code, identifiers, comments, commit messages, README and all other docs, PR descriptions, issues.

The only exception is user-facing copy (site UI and CMS admin UI labels), which is Polish by default. Every UI must also offer English via a language switch.
